お客様が自分で作ったデザインが、Illustratorでそのまま開ける原寸ベクターと加工指示書として店舗に届きます。描き起こし作業なしで製作に入れます。

第1部　お客様向け

使い方の流れ（3ステップ）

Illustratorなどの専用ソフトは不要。誰でもWeb上で簡単にデザインでき、その場で概算金額が分かります。画面下の帯には、いつでも 概算合計金額（税込） が表示されます。

1

商品を選ぶ

Tシャツ・ポロ・パーカー・キャップ・トート・タオルなどから選択。参考価格・対応加工・カラー数が一覧で分かります。

2

デザインする

本体カラーを選び、テンプレ・文字・スタンプ・画像を配置。プリント位置ごとに加工方法も選べます。

3

お見積もり

サイズごとの枚数を入力すると、明細つきの金額が自動計算。見積書の印刷・注文まで進めます。

デザインの操作・仕上がり確認

🧰 左メニューの道具

メニューできること
👕 カラー商品本体の色を変える／商品を変更する（商品変更時は今のデザインを引き継げます。位置・大きさは新しいプリント範囲へ自動調整）
📐 テンプレ定番デザイン（チームロゴ・クラスT・名入れ 等）をワンクリックで配置。文字は後から書き換え可
Ｔ テキスト文字を追加。書体は45種類（極太・袋文字・毛筆・ポップ・欧文筆記体など）。色・フチ取り・文字間隔・アーチ変形・縦書き（名入れ向け）
★ スタンプ内蔵イラストを配置。色は自由に変更可
⬆ 画像画像（JPG/PNG/GIF/WebP）をアップロード。「✨ 背景を消す」でロゴの白背景をワンタップ透過（強さ3段階・元に戻す付き）。解像度が低いと警告が出ます
🧵 加工方法プリント位置ごとに「刺繍／シルクスクリーン／フルカラー」を選択

✋ 操作のコツ

  • 移動：マウスは右ボタンでドラッグ（左クリックは選択）。スマホ・タブレットは指でドラッグ。中央に近づくとガイド線が出て吸着します。
  • 拡大・縮小／回転：選ぶと出る青い枠の角（□）で拡縮、上の丸（○）で回転。
  • 微調整：選択中に矢印キーで移動（Shift＋矢印で大きく）。
  • 複製 / 中央 / 反転：上部ツールバーのボタン（選択中に表示）。
  • 重ね順：右の「重ね順（レイヤー）」で前後入替・削除。
  • もどる／やり直す：上部ツールバー、または Ctrl+Z / Ctrl+Y。
  • 拡大表示：2本指ピンチ（タブレット・スマホ）／マウスホイール。表示移動（スクロール）も右ボタンでドラッグ（スマホは指）。「全体」で元に戻る。
  • プリント位置：キャンバス上部「📍 プリント位置」のサムネイル（前面・背面・左胸・袖 等）で切替。位置ごとに別デザイン・別加工が可能。

👁 仕上がりの確認（イメージのしやすさ最優先）

ボタン内容
👁 仕上がり枠線を消して完成イメージを確認。刺繍は糸の立体感、プリントは生地の質感で表示されます。
🧍 着用モデルが実際に着た写真で確認（定番Tシャツ・ドライTシャツ・ポロシャツ・パーカー）。選んだ色に服だけが変わり、デザインも合成されます。前面・背面・左右袖に対応。
🔍 全面前面・背面をまとめて1画面で確認。全体のバランスをチェックできます。
⊞ グリッド位置合わせ用の方眼を表示。

加工方法の選び方

🧵

刺繍

ロゴ・ネーム入れ向け。糸色パレットから選択（最大6色）。写真は不可。高級感が出ます。

🖨

シルクスクリーン

1〜4色のデザイン向け。枚数が多いほど1枚が割安。版代がかかります。

🎨

フルカラー

写真・グラデもそのまま。版代なし・1枚から。インクジェット。

💡プリント位置ごとに加工方法を変えられます（例：前面はフルカラー、左胸は刺繍）。色数・サイズ・数量から自動でお見積もりします。

チームユニフォーム（背番号・名前の一括入力）NEW

野球・サッカー・クラスTシャツなど、1人ずつ名前と背番号が違うユニフォームをまとめて作れます。

  • ① STEP2で、名前を入れたい文字を {名前}、背番号を入れたい文字を {番号} にしておく（英語表記は {NAME} / {NUMBER} でもOK）。
  • ② STEP3の「👕 チームユニフォーム（背番号・名前の一括入力）」を開く。
  • ③ 名簿を 1行に「名前, 番号, サイズ」 の形式で入力。
山田太郎, 10, L
佐藤花子, 7, M
鈴木一郎, 23, XL
  • ④ 「名簿を使う」にチェックを入れると、数量が名簿から自動集計され見積もりに反映。
  • ⑤ 「🔍 名簿プレビュー」で、全員分の仕上がり（名前・番号を差し替えたもの）を一覧確認。
📦注文・入稿すると、メンバー1人ずつの入稿データ（名前・番号入り）と、名簿一覧つきの指示書が生成されます。

🛒 ご注文の流れ

  • ① ご注文者情報を入力（お名前・会社名／メール／電話番号は必須。納期・住所・備考は任意）。
  • ② 利用規約・特定商取引法の表記に同意のチェックを入れる。
  • ③ 「この内容で注文する ▶」を押すと、注文内容に入稿データ（原寸SVG・プレビューPNG・デザインデータ）を添えて店舗へ送信（設定によりメールが開く場合も）。
  • ④ 送信後、注文番号つきの完了画面が表示されます。
🧾この時点では料金は発生しません。店舗がデザインを確認後、正式なお見積もり・納期をご案内します。

よくある質問（FAQ）

ソフトのインストールは必要？
いいえ。ブラウザだけで使えます（スマホ・タブレット対応）。
作りかけを保存できる？
自動保存されます。「💾 保存」で手元にファイル保存、「🔗 共有」でURL共有もできます。
写真をプリントできる？
「フルカラー（インクジェット）」を選べば写真もそのままプリントできます。刺繍・シルクは色数に制限があります。
注文したらすぐ請求される？
いいえ。注文送信は「申し込み」です。店舗の確認・正式見積もりの後に進みます。
濃い色の生地に白抜き文字はできる？
できます。シルクの場合は白下地版が必要になることがあり、その旨は店舗側の指示書に自動表示されます。
第2部　運営（店舗）向け

開業前チェックリスト

公開して注文を受け付ける前に、次を必ず設定してください。開業前チェックページ（setup.html）で設定の自動診断とテスト送信ができます。

  • SHOP … 会社名・住所・TEL・メール・税率・端数処理・送料を自社の内容に
  • PRODUCTS / METHODS / QTY_TIERS … 価格をすべて自社の価格表に（初期値はサンプル）
  • LEGAL … 特定商取引法の表記（通信販売では法的に必須）を実在の事業者情報に
  • ORDER … 注文の受信先（フォーム連携 or メール）を設定し、テスト送信で受信確認
  • （任意）assets/products/ に商品写真を置き photos を設定

価格・商品の変更

このサービスは ビルド不要の静的サイト です。設定ファイル js/config.js を書き換えるだけで、画面・見積もり・見積書・注文すべてに反映されます。

変更したいもの場所（js/config.js 内）
会社名・住所・TEL・メールSHOP
消費税率・端数処理・送料・送料無料ライン・見積有効期限SHOP（taxRate / taxRounding / shippingFee / freeShippingMin / quoteValidDays）
数量による段階割引QTY_TIERS
商品（名前・単価・サイズ・カラー・プリント位置・対応加工）PRODUCTS
加工賃・版代/型代・色数上限METHODS
刺繍糸の色 / インクの色THREAD_COLORS / INK_COLORS
フォントFONTS
⚠️現在の価格・商品はサンプル値です。公開前に必ず貴社の価格表に書き換えてください。消費税は小計にのみ課税し、送料（税込）は二重課税しない設計です。

注文の受け取り設定（フォーム連携）更新

js/config.js の ORDER ブロックで、注文の届き方を設定します。バックエンド不要のまま、注文を確実に受け取れます。

const ORDER = {
  provider: "mailto",     // "formspree" | "web3forms" | "getform" | "custom" | "mailto"
  endpoint: "",           // 例) "https://formspree.io/f/xxxxxxx"
  accessKey: "",          // web3forms を使う場合の access_key
  toEmail: "info@example.com", // mailto フォールバック時の送信先
  attachFiles: true,      // 入稿SVG・プレビューPNG・デザインJSONを添付/同送
  autoNumber: "ORD",      // 注文番号の接頭辞（例 ORD-20260707-1234）
};

推奨：フォーム自動受信の設定

  • Formspree または Web3Forms 等で無料登録。
  • 発行された送信先URL（またはアクセスキー）を endpoint（web3formsは accessKey）に貼り付け。
  • provider を "formspree" などに設定。
✅これだけで、GitHub Pages の静的サイトのまま注文内容＋入稿データが貴社に届きます。endpoint が空の場合は自動的にメール（mailto）方式にフォールバックします。設定後は必ず setup.html のテスト送信で受信を確認してください。

入稿データの受取・製作NEW

お客様が注文すると、注文内容とあわせて次の入稿データが届きます（attachFiles: true の場合）。STEP3の「📦 入稿データ一式」で店舗側からも同じデータを書き出せます。

  • 面別の入稿SVG（原寸・モックアップなし）：Illustratorでそのまま開ける原寸ベクター。プリント位置ごとに1ファイル。
  • 透過PNG：位置確認・校正用。
  • 入稿指示書（HTML）：加工方法・色（糸/インクの実色コード）・サイズ（mm）・位置を面ごとに明記。
  • デザインデータ（.json）：再編集・再現用。

🖨 製作時の注意（指示書に自動表示）

  • 入稿SVGには画面表示用の質感・立体効果は入りません（クリーンな版下データ）。
  • 濃色ボディ×シルクで白抜き等がある場合、白下地版（アンダーベース）が必要な旨を自動警告。
  • フォントは環境差を避けるため、店舗側でアウトライン化して製版する運用を推奨（指示書に記載）。
  • チーム名簿を使った注文では、メンバー1人ずつの入稿SVGと名簿一覧つき指示書が生成されます。

特商法・商品写真・公開

⚖️ 特商法・利用規約

通信販売では特定商取引法に基づく表記が必須です。js/config.js の LEGAL ブロックに実在の事業者情報（販売事業者名・運営責任者・住所・連絡先・支払方法・返品条件 等）を記入してください。内容は terms.html に表示され、注文時に同意チェックが求められます。

📷 商品写真への差し替え（photos / photoAreas）

assets/products/ に写真を置き、js/config.js の商品に photos を設定すると、イラストの代わりに実写真が表示されます（無い色・面はイラストに自動フォールバック）。写真の胸・背中の位置が版面とズレる場合は photoAreas を足すと、写真使用時だけプリント範囲を写真に合わせられます。

photos: { front: "assets/products/tshirt_front.png", back: "..." },
photoAreas: [   // printAreas をコピーし x/y/w/h を写真に合わせる（id は同じ）
  { id:"front", name:"前面", view:"front", x:250, y:250, w:200, h:260, mmW:300, mmH:360 },
],

※ 斜め・遠近のある写真に完全に沿わせる（変形合成）は今後対応予定。現状は正面平置き・トルソー正面が最もきれいに合います。詳細は assets/products/README.md。

👕 作品集ページの更新（works.html）

制作事例のギャラリー（トップの「👕 作品集」）。お客様の作品を載せるほど信頼と注文につながります。追加は2ステップ：

  1. 作品写真を assets/works/ にアップロード（GitHubで「Add file > Upload files」→ 最後に Commit changes）。
  2. js/works-data.js の WORKS = [ のすぐ下に1ブロック追記：
{
  img:   "assets/works/写真ファイル名.jpg",
  title: "野球チーム○○様 ユニフォームTシャツ",
  note:  "背番号・ネーム入りをシルクスクリーンで30枚。",
  tags:  ["Tシャツ", "チームウェア"],
  sample: false,   // 実際の作品は false（サンプルは true）
},

※ 掲載前に必ずお客様の許可を。いまの4件は「制作イメージ」のサンプルです（実作品が増えたら削除OK）。
