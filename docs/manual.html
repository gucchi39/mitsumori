第1部　お客様向け

使い方の流れ（3ステップ）

Illustratorなどの専用ソフトは不要。誰でもWeb上で簡単にデザインでき、その場で概算金額が分かります。画面下の帯には、いつでも 概算合計金額 が表示されます。

1

商品を選ぶ

Tシャツ・ポロ・パーカー・キャップ・トート・タオルなどから選択。参考価格・対応加工・カラー数が一覧で分かります。

2

デザインする

本体カラーを選び、テンプレ・文字・スタンプ・画像を配置。プリント位置ごとに加工方法も選べます。

3

お見積もり

サイズごとの枚数を入力すると、明細つきの金額が自動計算。見積書の印刷・注文まで進めます。

デザインの操作

🧰 左メニューの道具

メニューできること
👕 カラー商品本体の色を変える／商品を変更する
📐 テンプレ定番デザイン（チームロゴ・クラスT・名入れ 等）をワンクリックで配置。文字は後から書き換え可
Ｔ テキスト文字を追加。書体・色・フチ取り・文字間隔・アーチ変形・縦書き（名入れ向け）
★ スタンプ内蔵イラストを配置。色は自由に変更可
⬆ 画像画像（JPG/PNG/GIF/WebP）をアップロード。解像度が低いと警告が出ます
🧵 加工方法プリント位置ごとに「刺繍／シルクスクリーン／フルカラー」を選択

✋ 操作のコツ

  • 移動：ドラッグ。中央に近づくとガイド線が出て吸着します。
  • 拡大・縮小／回転：選ぶと出る青い枠の角（□）で拡縮、上の丸（○）で回転。
  • 微調整：選択中に矢印キーで移動（Shift＋矢印で大きく）。
  • 複製 / 中央 / 反転：上部ツールバーのボタン（選択中に表示）。
  • 重ね順：右の「重ね順（レイヤー）」で前後入替・削除。
  • もどる／やり直す：上部ツールバー、または Ctrl+Z / Ctrl+Y。
  • 拡大表示：2本指ピンチ（タブレット・スマホ）／マウスホイール。空白部分のドラッグで表示移動、「全体」で元に戻る。
  • 仕上がりプレビュー：枠線を消して完成イメージを確認。
  • プリント位置：画面下のサムネイル（前面・背面・左胸・袖 等）で切替。位置ごとに別デザイン・別加工が可能。

加工方法の選び方

🧵

刺繍

ロゴ・ネーム入れ向け。糸色パレットから選択（最大6色）。写真は不可。高級感が出ます。

🖨

シルクスクリーン

1〜4色のデザイン向け。枚数が多いほど1枚が割安。版代がかかります。

🎨

フルカラー

写真・グラデもそのまま。版代なし・1枚から。インクジェット。

💡プリント位置ごとに加工方法を変えられます（例：前面はフルカラー、左胸は刺繍）。色数・サイズ・数量から自動でお見積もりします。

第2部　運営（店舗）向け

価格・商品の変更

このサービスは ビルド不要の静的サイト です。設定ファイル js/config.js を書き換えるだけで、画面・見積もり・見積書すべてに反映されます。

加工賃・版代/型代・色数上限METHODS

⚠️現在の価格・商品はサンプル値です。公開前に必ず貴社の価格表に書き換えてください。

注文の受取・公開・運用

📨 注文データの受け取り（現状）

「✉ 注文・問い合わせ」ボタンで、注文内容を本文にしたメールが作成されます。お客様には、デザインデータ（💾 保存した .json ファイル）を添付して送っていただく運用です。

🚧より確実に注文データを受け取る仕組み（フォーム自動受信・入稿データの品質向上）は現在改善を進めています。

🧰 開業前チェック

開業前チェックページで、設定の自動診断と注文受信のテスト送信ができます。公開前に一度ご確認ください。

📷 商品写真への差し替え

assets/products/ に写真を置き、js/config.js の商品に photos を設定すると、イラストの代わりに実写真が表示されます（無い色・面はイラストに自動フォールバック）。

🚀 公開・更新

  • GitHub Pages で自動公開済み。指定ブランチにプッシュすると数分で公開URLに反映されます。
  • レンタルサーバー等にフォルダごとアップロードしても動作します。

🧪 動作確認（開発者向け）

見積もり計算のテストがあります。

node --test tests/quote.test.js

🆘 困ったときは

  • 価格がおかしい → js/config.js の価格表と税率・送料を確認。
  • 商品を追加したい → PRODUCTS に1件追加（既存をコピーして書き換えるのが簡単）。
  • 画面が崩れる／動かない → ブラウザを最新版に更新。
