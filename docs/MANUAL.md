# ミツモリ デザインシミュレーター 操作マニュアル

オリジナルウェアをWeb上でデザインし、その場で自動見積もり・ご注文まで完結できるサービスです。
このマニュアルは **お客様向けの使い方（第1部）** と **運営（店舗）向けの設定・運用（第2部）** の2部構成です。

- 公開URL（本番）: https://gucchi39.github.io/mitsumori/
- 使い方マニュアル（HTML版）: [docs/manual.html](manual.html)
- 開業前チェック（設定診断・受信テスト）: [docs/setup.html](setup.html)
- 特商法・利用規約: [docs/terms.html](terms.html)

## 全体の流れ（このサービスでできること）

```
お客様                                          店舗（貴社）
─────────────────────────────       ──────────────────────
① 商品を選ぶ
② Web上でデザイン（文字・スタンプ・画像）
③ その場で自動見積もり
④ 仕上がり・全面プレビューで確認
⑤ ご注文者情報を入力して注文送信  ───────▶  ⑥ 注文内容＋入稿データを受信
                                              （メール or フォーム自動受信）
                                           ⑦ 入稿データ一式（原寸SVG＋指示書）で製作
                                           ⑧ 刺繍・プリントして納品
```

**ポイント**：お客様が自分で作ったデザインが、**Illustratorでそのまま開ける原寸ベクター（SVG）** と
**加工指示書** として店舗に届きます。デザインの描き起こし作業なしで製作に入れます。

# 第1部　お客様向け：使い方

デザインは **3ステップ** で完成します。画面上部のステップ表示（① 商品選択 → ② デザイン → ③ お見積もり）で今どこにいるか分かります。
画面下の帯には、いつでも **概算合計金額（税込）** が表示されます。

## STEP 1　商品を選ぶ

1. 一覧から作りたい商品を選んでクリックします（Tシャツ・ドライTシャツ・ポロシャツ・パーカー・キャップ・トートバッグ・タオル など）。
2. 各カードに、1枚あたりの参考価格・対応する加工方法・カラー数が表示されています。

## STEP 2　デザインする

左側の黒いメニューバーから道具を選びます。

| メニュー | できること |
|---|---|
| **👕 カラー** | 商品本体の色を変える／商品を変更する（**商品変更時は今のデザインを引き継げます**。位置・大きさは新しいプリント範囲へ自動調整） |
| **📐 テンプレ** | 定番デザイン（チームロゴ・クラスT・名入れ 等）をワンクリックで配置。文字だけ後で書き換え可 |
| **Ｔ テキスト** | 文字を追加。**書体は45種類**（極太・袋文字・毛筆・ポップ・欧文筆記体など）。色・フチ取り・文字間隔・**アーチ変形**・**縦書き**（名入れ向け） |
| **★ スタンプ** | 内蔵イラストを配置。色は自由に変更可 |
| **⬆ 画像** | お手持ちの画像（JPG/PNG/GIF/WebP）をアップロード。**「✨ 背景を消す」でロゴの白背景をワンタップ透過**。解像度が低いと警告が出ます |
| **🧵 加工方法** | プリント位置ごとに「刺繍／シルクスクリーン／フルカラー」を選択 |

> **背景透過のコツ**：白背景のロゴ画像を選択して「✨ 背景を消す」を押すと、外側とつながった背景だけが透明になります（文字の白フチなどデザインの白は残ります）。強さは「弱・標準・強」から選べ、「↩ 元に戻す」でいつでも復元できます。

### デザインの操作

- **移動**：マウスは**右ボタンでドラッグ**（左クリックは選択）。スマホ・タブレットは指でドラッグ。中央に近づくとガイド線が出て吸着します。
- **拡大・縮小／回転**：デザインを選ぶと出る青い枠の角（□）で拡縮、上の丸（○）で回転。
- **微調整**：選択中に矢印キーで少しずつ移動（Shift＋矢印で大きく移動）。
- **複製 / 中央 / 反転**：上部ツールバーのボタン（選択中に表示）。
- **重ね順**：右側の「重ね順（レイヤー）」で前後を入れ替え・削除。
- **もどる／やり直す**：上部ツールバー、または Ctrl+Z / Ctrl+Y。
- **拡大表示**：2本指ピンチ（タブレット・スマホ）／マウスホイール。空白部分のドラッグで表示位置を移動。「全体」ボタンで元に戻ります。

### 仕上がりの確認（イメージのしやすさ最優先）

| ボタン | 内容 |
|---|---|
| **👁 仕上がり** | 枠線を消して完成イメージを確認。刺繍は糸の立体感、プリントは生地の質感で表示されます。 |
| **🔍 全面** | 前面・背面をまとめて1画面で確認。全体のバランスをチェックできます。 |
| **⊞ グリッド** | 位置合わせ用の方眼を表示。 |

- **プリント位置の切替**：キャンバス上部の「📍 プリント位置」サムネイル（前面・背面・左胸・袖 等）で切り替え。位置ごとに別のデザイン・加工方法を設定できます。

### 加工方法の目安

- **🧵 刺繍**：ロゴ・ネーム入れ向け。糸色パレットから選択（最大6色）。写真は不可。高級感が出ます。
- **🖨 シルクスクリーン**：1〜4色のデザイン向け。枚数が多いほど1枚が割安。版代がかかります。
- **🎨 フルカラー（インクジェット）**：写真・グラデもそのまま。版代なし・1枚から。

> プリント位置ごとに加工方法を変えられます（例：前面はフルカラー、左胸は刺繍）。

## STEP 3　数量を入れてお見積もり

1. サイズごとの枚数を入力します（数量が多いほど1枚あたりが安くなります）。
2. 右側にお見積もり明細（商品代・版代/型代・加工代・消費税・送料・合計）が自動表示されます。
3. 送料は税込880円（30,000円以上で無料）※金額は運営設定により異なります。

## チームユニフォーム（背番号・名前の一括入力）★

野球・サッカー・クラスTシャツなど、**1人ずつ名前と背番号が違う**ユニフォームをまとめて作れます。

**手順**

1. **STEP 2** で、名前を入れたいテキストを **`{名前}`**、背番号を入れたいテキストを **`{番号}`** にしておきます
   （英語表記は `{NAME}` / `{NUMBER}` でもOK）。
2. **STEP 3** の「👕 チームユニフォーム（背番号・名前の一括入力）」を開きます。
3. 名簿を **1行に「名前, 番号, サイズ」** の形式で入力します。

   ```
   山田太郎, 10, L
   佐藤花子, 7, M
   鈴木一郎, 23, XL
   ```

4. **「名簿を使う」** にチェックを入れると、**数量が名簿から自動集計**され、見積もりに反映されます。
5. **「🔍 名簿プレビュー」** で、全員分の仕上がり（名前・番号を差し替えたもの）を一覧確認できます。

> 注文・入稿すると、**メンバー1人ずつの入稿データ（名前・番号入り）** と、名簿一覧つきの指示書が生成されます。

## 保存・共有

| ボタン | 内容 |
|---|---|
| **🔗 共有** | 今のデザインをURL化してコピー。相手に送ると同じデザイン・見積もりが再現されます（サーバー不要。※画像・個人情報は含まれません） |
| **📁 マイデザイン** | **このブラウザに名前を付けて保存**（最大12件・サムネイル付き）。リピート注文や作り直しに便利。名簿もいっしょに保存されます |
| **💾 保存** | デザインをファイル（.json）に保存 |
| **📂 読込** | 保存したファイルを読み込み |
| **✚ 新規** | 最初からやり直す |

> 作成中のデザインは自動保存され、次に開いたとき「続きから再開」できます。
> **リピート注文のおすすめ**：注文したデザインは「📁 マイデザイン」に保存しておくと、次回は読み込んで枚数を入れるだけで再注文できます（端末・ブラウザを変えると引き継がれないため、大事なデザインは「💾 保存」のファイルも併用を）。

## ご注文の流れ

お見積もりに納得したら、そのまま注文まで進めます。

1. **ご注文者情報** を入力します（お名前・会社名／メール／電話番号は **必須**。納期・住所・備考は任意）。
2. **利用規約・特定商取引法の表記** に同意のチェックを入れます。
3. **「この内容で注文する ▶」** を押すと、注文内容に **入稿データ（原寸SVG・プレビューPNG・デザインデータ）を添えて** 店舗へ送信されます
   （設定によりメール送信が開く場合もあります）。
4. 送信後、注文番号つきの完了画面が表示されます。

> この時点では料金は発生しません。店舗がデザインを確認後、正式なお見積もり・納期をご案内します。

### 見積書・データの書き出し

| ボタン | 内容 |
|---|---|
| **🖨 見積書を印刷（PDF保存）** | 宛名・金額入りの御見積書を印刷／PDF保存 |
| **📦 入稿データ一式** | 面別の原寸SVG＋透過PNG＋指示書＋デザインデータをまとめて書き出し |
| **📋 入稿指示書を印刷** | 加工方法・色・サイズ・位置をまとめた指示書を印刷 |
| **SVG（面別）/ PNG画像 / デザインデータ** | 個別に書き出し |

## よくある質問（FAQ）

- **Q. ソフトのインストールは必要？** いいえ。ブラウザだけで使えます（スマホ・タブレット可）。
- **Q. 作りかけを保存できる？** 自動保存されます。「💾 保存」で手元にファイル保存、「🔗 共有」でURL共有もできます。
- **Q. 写真をプリントできる？** 「フルカラー（インクジェット）」を選べば写真もそのままプリントできます（刺繍・シルクは色数に制限）。
- **Q. 注文したらすぐ請求される？** いいえ。注文送信は「申し込み」です。店舗の確認・正式見積もりの後に進みます。
- **Q. 濃い色の生地に白抜き文字はできる？** できます。シルクの場合は白下地版が必要になることがあり、その旨は店舗側の指示書に自動表示されます。

# 第2部　運営（店舗）向け：設定・運用

このサービスは **ビルド不要の静的サイト**（HTML/CSS/JavaScript）です。専門知識がなくても、設定ファイル1つで価格・商品・注文受信を変更できます。

## ✅ 開業前チェックリスト

公開して注文を受け付ける前に、次を必ず設定してください。**[開業前チェックページ（setup.html）](setup.html)** で設定の自動診断とテスト送信ができます。

- [ ] `SHOP` … 会社名・住所・TEL・メール・**税率・端数処理・送料** を自社の内容に
- [ ] `PRODUCTS` / `METHODS` / `QTY_TIERS` … **価格をすべて自社の価格表に**（初期値はサンプル）
- [ ] `LEGAL` … **特定商取引法の表記**（通信販売では法的に必須）を実在の事業者情報に
- [ ] `ORDER` … 注文の受信先（フォーム連携 or メール）を設定し、**テスト送信で受信確認**
- [ ] （任意）`assets/products/` に商品写真を置き `photos` を設定

## 価格・商品の変更（いちばん大事）

すべて **`js/config.js`** を書き換えるだけで、画面・見積もり・見積書・注文に反映されます。

| 変更したいもの | 場所（`js/config.js` 内） |
|---|---|
| 会社名・住所・TEL・メール | `SHOP` |
| 消費税率・**端数処理**（切捨/四捨五入/切上）・送料・送料無料ライン・見積有効期限 | `SHOP`（`taxRate` / `taxRounding` / `shippingFee` / `freeShippingMin` / `quoteValidDays`） |
| 数量による段階割引の区切り | `QTY_TIERS` |
| 商品（名前・単価・サイズ・カラー・プリント位置・対応加工方法） | `PRODUCTS` |
| 加工賃・版代/型代・色数上限 | `METHODS` |
| 刺繍糸の色 | `THREAD_COLORS` |
| シルク用インクの色 | `INK_COLORS` |
| フォント | `FONTS` |

> ⚠️ 現在の価格・商品は**サンプル値**です。公開前に必ず貴社の価格表に書き換えてください。
> 消費税は小計にのみ課税し、送料（税込）は二重課税しない設計です。端数処理は `taxRounding` で切替できます。

## 注文の受け取り設定（フォーム連携）

`js/config.js` の **`ORDER`** ブロックで、注文の届き方を設定します。バックエンド不要のまま、注文を確実に受け取れます。

```js
const ORDER = {
  provider: "mailto",     // "formspree" | "web3forms" | "getform" | "custom" | "mailto"
  endpoint: "",           // 例) "https://formspree.io/f/xxxxxxx"
  accessKey: "",          // web3forms を使う場合の access_key
  toEmail: "info@example.com", // mailto フォールバック時の送信先
  attachFiles: true,      // 入稿SVG・プレビューPNG・デザインJSONを添付/同送
  autoNumber: "ORD",      // 注文番号の接頭辞（例 ORD-20260707-1234）
};
```

**推奨（フォーム自動受信）の設定手順**

1. [Formspree](https://formspree.io) または [Web3Forms](https://web3forms.com) 等で無料登録
2. 発行された送信先URL（またはアクセスキー）を `endpoint`（web3formsは `accessKey`）に貼り付け
3. `provider` を `"formspree"` などに設定

これだけで、GitHub Pages の静的サイトのまま **注文内容＋入稿データが貴社に届きます**。
`endpoint` が空の場合は自動的に **メール（mailto）方式** にフォールバックします。

> 設定後は必ず [開業前チェックページ（setup.html）](setup.html) の **テスト送信** で、実際に受信できることを確認してください。

## 入稿データの受け取り・製作

お客様が注文すると、注文内容とあわせて次の入稿データが届きます（`attachFiles: true` の場合）。
STEP3の **「📦 入稿データ一式」** で店舗側からも同じデータを書き出せます。

- **面別の入稿SVG（原寸・モックアップなし）** … Illustratorでそのまま開ける原寸ベクター。プリント位置ごとに1ファイル。
- **透過PNG** … 位置確認・校正用。
- **入稿指示書（HTML）** … 加工方法・色（糸/インクの実色コード）・サイズ（mm）・位置を面ごとに明記。
- **デザインデータ（.json）** … 再編集・再現用。

**製作時の注意（指示書に自動表示されます）**

- 入稿SVGには **画面表示用の質感・立体効果は入りません**（クリーンな版下データ）。
- 濃色ボディ × シルクスクリーンで白抜き等がある場合、**白下地版（アンダーベース）** が必要な旨を自動で警告表示します。
- フォントは環境差を避けるため、**店舗側でアウトライン化** して製版する運用を推奨します（指示書に記載）。
- チーム名簿を使った注文では、**メンバー1人ずつの入稿SVG** と名簿一覧つき指示書が生成されます。

## 特商法・利用規約

通信販売では **特定商取引法に基づく表記** が必須です。`js/config.js` の **`LEGAL`** ブロックに
実在の事業者情報（販売事業者名・運営責任者・住所・連絡先・支払方法・返品条件 等）を記入してください。
内容は **[docs/terms.html](terms.html)** に表示され、注文時に同意チェックが求められます。

## 商品写真への差し替え（実写真で見せる）

`assets/products/` に写真を置き、`js/config.js` の商品に **`photos`** を設定すると、
イラストの代わりに実写真がシミュレーターに表示されます（該当色・面の写真が無ければ自動でイラストに戻ります）。

```js
photos: { front: "assets/products/tshirt_front.png", back: "assets/products/tshirt_back.png" },
```

写真の胸・背中の位置がイラスト用の版面とズレる場合は、商品に **`photoAreas`** を足すと、
**写真使用時だけプリント範囲を写真に合わせられます**（詳細は `assets/products/README.md`）。

```js
photoAreas: [   // printAreas をコピーし、x/y/w/h を写真に合わせて調整（id は同じ）
  { id: "front", name: "前面", view: "front", x: 250, y: 250, w: 200, h: 260, mmW: 300, mmH: 360 },
],
```

> ※ 斜め・遠近のある写真に完全に沿わせる（変形合成）は今後の対応予定です。現状は正面平置き・トルソー正面の写真が最もきれいに合います。

## 作品集ページの更新（works.html）

制作事例のギャラリーページがあります（トップの「👕 作品集」から開けます）。
**お客様の作品を載せるほど信頼と注文につながる**ので、納品のたびに増やすのがおすすめです。

**作品を1件追加する手順（2ステップ）**

1. 作品写真を **`assets/works/`** にアップロード
   （GitHubで assets/works フォルダを開く → 「Add file > Upload files」→ 最後に **Commit changes** を必ず押す）。
2. **`js/works-data.js`** を開いて「Edit」し、`WORKS = [` のすぐ下に次の5行を追記して保存：

```js
{
  img:   "assets/works/写真ファイル名.jpg",
  title: "野球チーム○○様 ユニフォームTシャツ",
  note:  "背番号・ネーム入りをシルクスクリーンで30枚。",
  tags:  ["Tシャツ", "チームウェア"],
  sample: false,   // 実際の作品は false（サンプルは true）
},
```

> **掲載前に必ずお客様の許可をもらってください**（名前・顔が写る場合は特に）。
> いま入っている4件は「制作イメージ」のサンプルです。実作品が増えたら削除してかまいません。

## 困ったときは

- **価格がおかしい** → `js/config.js` の価格表と `SHOP` の税率・送料を確認。
- **注文が届かない** → `ORDER` の設定を確認し、[setup.html](setup.html) でテスト送信。`endpoint` 空ならメール方式になります。
- **商品を追加したい** → `PRODUCTS` に1件追加（既存商品をコピーして書き換えるのが簡単です）。
- **写真の版面がずれる** → 商品に `photoAreas` を足して位置を微調整。
- **画面が崩れる／動かない** → ブラウザを最新版に更新。それでも直らなければ、状況をお知らせください。
