# ミツモリ デザインシミュレーター 操作マニュアル

オリジナルウェアをWeb上でデザインし、その場で自動見積もりできるサービスです。
このマニュアルは **お客様向けの使い方** と **運営（店舗）向けの設定・運用** の2部構成です。

- 公開URL（本番）: https://gucchi39.github.io/mitsumori/

---

# 第1部　お客様向け：使い方

デザインは **3ステップ** で完成します。画面上部のステップ表示（① 商品選択 → ② デザイン → ③ お見積もり）で今どこにいるか分かります。
画面下の帯には、いつでも **概算合計金額** が表示されます。

## STEP 1　商品を選ぶ

1. 一覧から作りたい商品を選んでクリックします（Tシャツ・ポロシャツ・パーカー・キャップ・トートバッグ・タオル など）。
2. 各カードに、1枚あたりの参考価格・対応する加工方法・カラー数が表示されています。

## STEP 2　デザインする

左側の黒いメニューバーから道具を選びます。

| メニュー | できること |
|---|---|
| **👕 カラー** | 商品本体の色を変える／商品を変更する |
| **📐 テンプレ** | 定番デザイン（チームロゴ・クラスT・名入れ 等）をワンクリックで配置。文字だけ後で書き換え可 |
| **Ｔ テキスト** | 文字を追加。書体・色・フチ取り・文字間隔・**アーチ変形**・**縦書き**（名入れ向け） |
| **★ スタンプ** | 内蔵イラストを配置。色は自由に変更可 |
| **⬆ 画像** | お手持ちの画像（JPG/PNG/GIF/WebP）をアップロード。解像度が低いと警告が出ます |
| **🧵 加工方法** | プリント位置ごとに「刺繍／シルクスクリーン／フルカラー」を選択 |

### デザインの操作

- **移動**：デザインをドラッグします。中央に近づくとガイド線が出て吸着します。
- **拡大・縮小／回転**：デザインを選ぶと出る青い枠の角（□）で拡縮、上の丸（○）で回転。
- **微調整**：選択中に矢印キーで少しずつ移動（Shift＋矢印で大きく移動）。
- **複製 / 中央 / 反転**：上部ツールバーのボタン（選択中に表示）。
- **重ね順**：右側の「重ね順（レイヤー）」で前後を入れ替え・削除。
- **もどる／やり直す**：上部ツールバー、または Ctrl+Z / Ctrl+Y。
- **拡大表示**：2本指ピンチ（タブレット・スマホ）／マウスホイール。空白部分のドラッグで表示位置を移動。「全体」ボタンで元に戻ります。
- **仕上がりプレビュー**：枠線を消して完成イメージを確認。刺繍は糸の立体感、プリントは生地の質感で表示されます。
- **着用イメージ（🧍 着用）**：トルソーに着せたイメージで確認。「🔍 全面」で前面・背面をまとめて確認。
- **プリント位置の切替**：画面下の位置サムネイル（前面・背面・左胸・袖 等）で切り替え。位置ごとに別のデザイン・加工方法を設定できます。

### 加工方法の目安

- **🧵 刺繍**：ロゴ・ネーム入れ向け。糸色パレットから選択（最大6色）。写真は不可。
- **🖨 シルクスクリーン**：1〜4色のデザイン向け。枚数が多いほど1枚が割安。版代がかかります。
- **🎨 フルカラー（インクジェット）**：写真・グラデもそのまま。版代なし・1枚から。

## STEP 3　数量を入れてお見積もり

1. サイズごとの枚数を入力します（数量が多いほど1枚あたりが安くなります）。
2. 右側にお見積もり明細（商品代・版代/型代・加工代・消費税・送料・合計）が自動表示されます。
3. 「お名前（宛名）」を入れると見積書に反映されます（任意）。

## 保存・共有・注文

画面右上と STEP3 のボタンで、次のことができます。

| ボタン | 内容 |
|---|---|
| **🔗 共有** | 今のデザインをURL化してコピー。相手に送ると同じデザイン・見積もりが再現されます（サーバー不要。※画像は含まれません） |
| **💾 保存** | デザインをファイル（.json）に保存 |
| **📂 読込** | 保存したファイルを読み込み |
| **✚ 新規** | 最初からやり直す |
| **🖨 見積書を印刷（PDF保存）** | 宛名・金額入りの御見積書を印刷／PDF保存 |
| **✉ この内容で注文・問い合わせ** | 注文内容を本文にしたメールを作成 |
| **PNG画像 / SVG（入稿用）/ デザインデータ** | 画像・ベクター・データで書き出し |

> 作成中のデザインは自動保存され、次に開いたとき「続きから再開」できます。

# 第2部　運営（店舗）向け：設定・運用

このサービスは **ビルド不要の静的サイト**（HTML/CSS/JavaScript）です。専門知識がなくても、設定ファイル1つで価格・商品を変更できます。

## 価格・商品の変更（いちばん大事）

すべて **`js/config.js`** を書き換えるだけで、画面・見積もり・見積書に反映されます。

| 変更したいもの | 場所（`js/config.js` 内） |
|---|---|
| 会社名・住所・TEL・メール | `SHOP` |
| 消費税率・**端数処理**（切捨/四捨五入/切上）・送料・送料無料ライン | `SHOP`（`taxRate` / `taxRounding` / `shippingFee` / `freeShippingMin`） |
| 数量による段階割引の区切り | `QTY_TIERS` |
| 商品（名前・単価・サイズ・カラー・プリント位置・対応加工方法） | `PRODUCTS` |
| 加工賃・版代/型代・色数上限 | `METHODS` |
| 刺繍糸の色 | `THREAD_COLORS` |
| シルク用インクの色 | `INK_COLORS` |
| フォント | `FONTS` |

> ⚠️ 現在の価格・商品は**サンプル値**です。公開前に必ず貴社の価格表に書き換えてください。

## 注文データの受け取り（現状）

現在は「✉ この内容で注文・問い合わせ」ボタンで、注文内容を本文にしたメールが作成されます。
お客様には、デザインデータ（💾 保存した .json ファイル）を添付して送っていただく運用です。

> より確実に注文データを受け取る仕組み（フォーム送信での自動受信・入稿データの品質向上）は現在改善を進めています。

## 公開・更新

- 公開はGitHub Pagesで自動化済みです。指定ブランチにプッシュすると数分で **https://gucchi39.github.io/mitsumori/** に反映されます。
- レンタルサーバー等にフォルダごとアップロードしても動作します。

## 動作確認（開発者向け）

見積もり計算のテストがあります。

```bash
node --test tests/quote.test.js
```

## ファイル構成

```
index.html          画面本体（3ステップ）
css/style.css       デザイン（アクセント色は先頭の変数で変更可）
js/config.js        ★ 店舗設定・商品・価格（ここを編集して運用）
js/quote.js         自動見積もりエンジン（テスト済み）
js/editor.js        デザインエディタ
js/mockups.js       商品モックアップ（SVG）
js/stamps.js        内蔵スタンプ素材
js/templates.js     デザインテンプレート
js/app.js           画面制御・見積書・保存/出力
tests/quote.test.js 見積もりのテスト
docs/               マニュアル・スクリーンショット
```

## 困ったときは

- **価格がおかしい** → `js/config.js` の価格表と `SHOP` の税率・送料を確認。
- **商品を追加したい** → `PRODUCTS` に1件追加（既存商品をコピーして書き換えるのが簡単です）。
- **画面が崩れる／動かない** → ブラウザを最新版に更新。それでも直らなければ、状況をお知らせください。
