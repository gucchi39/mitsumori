2注文の自動受信を設定する（推奨）

いまは — で動作しています。外部フォームサービスを設定すると、お客様の端末環境に関係なく注文＋入稿データが自動で貴社に届きます（無料枠で開始可能）。

Formspree の場合（かんたん・推奨）

  1. formspree.io でアカウント登録（受信したいメールアドレスで）
  2. 「New form」でフォームを作成 → エンドポイントURL（例 https://formspree.io/f/abcdwxyz）をコピー
  3. js/config.js の ORDER を書き換え： 
    const ORDER = {
  provider: "formspree",
  endpoint: "https://formspree.io/f/abcdwxyz", // ←コピーしたURL
  toEmail: "貴社の受信メール@example.com",
  attachFiles: true,
  autoNumber: "ORD",
};
  4. 保存してサイトを更新（GitHubへプッシュ）
  5. 下の「テスト送信」ボタンで届くか確認

Web3Forms の場合

  1. web3forms.com でメールを入れて Access Key を取得
  2. provider: "web3forms"、endpoint: "https://api.web3forms.com/submit"、accessKey: "取得したキー" を設定

※ 無料枠は月間送信数・添付容量に上限があります。写真入り注文が多い場合は有料プランをご検討ください。

3受信テスト

設定したエンドポイントへテスト注文を送ります。数分以内に受信メールが届けば成功です。

4公開前の最終チェック（手動）

  • ☐価格表：js/config.js の商品単価・加工賃・版代/型代を貴社の実価格に更新した
